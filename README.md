A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty ($500 pot, top 50 share). The joke: I bought GTA V on PS3 in 2013, bought it again on PS4, bought it again on PS5 — and now Rockstar wants me to buy a whole PS6 for GTA 6. Three $60 game cases, one very patient make.fun ghost watching the whole thing, and the punchline in big letters across the bottom. The meme (`meme.png`, 1024x576) is posted on X from a public account with a make.fun link, @makefunai and the play code `makefun-granite-seal-brownie`, telling readers that people and their AI agents earn real money in make.fun's bounties.

make.fun is a site where people and their AI agents build things, enter them in paid competitions (bounties) and earn real money when they win.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the X post's address) from this repository to the output directory, where the gate reads it. That is all the program has to do — the post itself is the entry.
